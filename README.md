# For Sanvi ❤️ - A Special Raksha Bandhan Surprise

A beautiful, emotional, cute, and highly interactive **Raksha Bandhan surprise website dedicated specially to Sanvi**.

Built with love using HTML5, CSS3, and modern vanilla JavaScript with interactive virtual rituals, personalized photo scrapbook, wax-sealed handwritten letter, 3D gift box unboxing, procedural sound effects, and festive animations.

## 🌸 Features

- **Landing Hero**: "For Sanvi ❤️" with gilded portrait frame and animated "Open Your Surprise ✨" button.
- **Virtual Rakhi Tying**: Traditional Puja thali with animated flickering Diya lamp, sweets, and golden Rakhi. Clicking "Tie the Rakhi ✨" animates golden silk threads, auspicious temple chimes, and reveals a heartfelt message.
- **Wax-Sealed Personal Letter**: Interactive vintage blush envelope with a wax seal stamped `S ❤️` that unfolds into a warm handwritten sibling letter.
- **Polaroid Scrapbook Gallery**: 5 interactive Polaroid cards with washi tape, 3D tilt effects, and an interactive Lightbox Modal with 3D flip-card handwritten memory notes.
- **"Things That Make Sanvi Special 💗"**: 4 interactive appreciation cards with tap-to-agree counters and micro-animations.
- **3D Virtual Gift Box 🎁**: Interactive gift box unboxing revealing redeemable VIP Sibling Vouchers and digital Shagun.
- **Festive 2026 Celebration & Grand Finale ✨**: Full-screen celebration fireworks, floating sky lanterns, and a personalized keepsake certificate.
- **Sibling Easter Eggs & Sound**:
  - 🔇/🎵 Ambient music toggle in the top bar playing gentle festive chimes synthesized with Web Audio API.
  - ⭐ Lucky Star Easter egg in the top navigation with secret sibling compliments.
  - 👀 Cheeky *"Don't click this"* button with playful banter.
  - 🤗 Floating *"Send Virtual Hug"* button that sends a warm pulse and heart shower across the screen.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python
python -m http.server 8080

# Or open directly
open index.html
```
